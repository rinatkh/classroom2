# Classroom 2: Go Core — переменные и типы

Репозиторий для live coding на занятии 2.

## Как запускать примеры

```bash
make run-declaration
make run-numbers
make run-bases
make run-floats-bool
make run-strings
make run-constants
make run-conversion
```

Или все сразу:

```bash
make run-all
```

## Идея занятия

В каждом `cmd/*/main.go` есть:

1. короткая теория прямо в коде;
2. пример, который можно запустить;
3. практическое задание на 3–5 минут;
4. ниже в комментариях — ответ, чтобы можно было разобрать после попытки ученика.
